Niche research for compilation channels,
right inside Claude.

Add this remote MCP server to your AI. It analyzes any YouTube channel by video type, guides you to one niche per channel with real data, and can license the T-TONGHOP Windows app that makes compilation videos with AI narration in 9 languages. No sign-in required.

Set up in one minute

Each app calls it something different (Connector, App, Plugin), but it is the same MCP standard: give it a name, paste the URL.

Claude

  1. Open claude.ai → Customize → Connectors.
  2. Click Add → Add custom connector.
  3. Name: T-TONGHOP, URL: the link above → Continue. Authentication: No sign-in → Add → Connect.
  4. In a chat, ask a question; Claude asks permission the first time it uses a tool.

ChatGPT

  1. Settings → Apps & Connectors.
  2. Turn on Developer mode (Advanced) if you don't see a Create button.
  3. Click Create: name T-TONGHOP, paste the link → Create.
  4. In a chat, pick T-TONGHOP from the tools menu.

Gemini · Grok · Cursor…

  1. Open the Connector / Plugin / MCP settings.
  2. Choose New connector → Custom.
  3. Name it, paste the link → Add.
