Get your API keys

Three keys, set up once.

The app uses your own API keys, so AI costs are transparent: you pay only for what you use. Paste the keys into the app once and never type them again.

1. OpenAI key

Required

AI watches each scene, scores the best moments, writes narration and picks the thumbnail. Uses gpt-4o-mini, OpenAI's cheapest model: usually a few cents per video.

  1. Go to platform.openai.com, sign up or log in with Google.
  2. Open Settings → Billing, click Add payment details, add a Visa/Mastercard and top up at least US$5 (enough for many videos).
  3. Open API keys, click Create new secret key, name it “T-TONG HOP”, click Create.
  4. Copy the key starting with sk- (shown only once, paste it right away).
  5. In the app click API keys at the top, paste into the OpenAI box, click SAVE.

2. GIPHY key

Free · optional

Lets the app download extra memes from GIPHY for the Funny topic. Without it the app still works with its built-in meme library.

  1. Go to developers.giphy.com/dashboard, click Sign Up with your email.
  2. Click Create an App, choose API (not SDK), click Next Step.
  3. App name “T-TONG HOP”, description “video compilation tool”, accept the terms, click Create App.
  4. Copy the string of letters and digits (that's the key).
  5. In the app click API keys, paste into the GIPHY box, click SAVE.

3. T-VOICE key (T-GIỌNG ĐỌC, tanseven.com)

Required for the 5 narrated topics

Voices the narration for Car crashes, Natural disasters, Planes & ships, Security cameras and Wildlife (9 languages). Basic 99,000 VND = 1.1 million characters, Pro 299,000 VND = 3.8 million characters; characters never expire. Follow VIDEO 2 button by button.

  1. Go to tanseven.com → Account, click Register (2,000 free trial characters).
  2. Click Top up, pick a pack, scan the QR with your banking app, transfer the exact amount and note. Characters are added within 1–2 minutes.
  3. Scroll to API keys, name it “T-TỔNG HỢP”, click Create new key, then Copy the key starting with tsv_ (shown only once).
  4. In the app click API keys at the top, paste into the T-VOICE key box, click SAVE. Green text “… characters left” means you're done.

Stuck on a step? Send a screenshot to the Zalo support group and Tân Seven will walk you through it. Never send your API keys to anyone, including in the group.
