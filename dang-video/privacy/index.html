Privacy Policy

Tan Seven Publisher (T-ĐĂNG VIDEO) · Last updated: October 22, 2026

Tan Seven Publisher ("the app") is a Windows desktop app made by Tan Seven ("we") that uploads videos a user has produced to the user's own YouTube channel. It is used by Tan Seven for its own channels and offered to other YouTube creators. This policy explains what Google user data the app accesses and how it is handled.

1. Data we access

When a channel owner signs in with Google and grants permission, the app receives:

  • OAuth access and refresh tokens for the authorized YouTube channel;
  • the channel's name and channel ID (via youtube.readonly, channels.list mine=true), used only to confirm the upload goes to the right channel;
  • the ID of each video the app uploads (returned by YouTube after videos.insert), used to set its thumbnail and to show the YouTube Studio link.

The app does not read videos, comments, subscribers, analytics, messages, viewer data, or any other content of the account.

2. How we use the data

  • Upload video files that the user selects to the channel the user authorized, as private videos, with the title, description, tags, category, language, synthetic-content declaration and thumbnail that we prepared.
  • Show the result (video ID and YouTube Studio link) to the user.

We do not use Google user data for advertising, profiling, selling, or training AI or machine-learning models.

3. Storage and security

  • Tokens are stored only on the user's own computer, in a private folder of the app (file permission 600). They are never sent to Tan Seven or anyone else.
  • Upload records (channel name, title, video ID, time) are kept in local log files on the same computer.
  • The app has no Tan Seven server in the upload path; it only listens on the local computer (127.0.0.1) and talks directly to Google's YouTube Data API.

4. Data protection mechanisms

We treat OAuth tokens and all Google user data as sensitive data and protect them as follows:

  • Encryption in transit: every request to Google (sign-in, token exchange, token refresh, upload, thumbnail, revoke) uses HTTPS with TLS encryption. The app never sends Google user data over unencrypted connections.
  • No central server: tokens and channel data never leave the user's computer and are never sent to or stored on any Tan Seven server, so there is no central database of user data that could be breached.
  • Access control at rest: tokens are saved in a private app folder readable only by the user's own operating-system account (folder permission 700, file permission 600). Other users of the computer cannot read them. We recommend users keep their computer's disk encryption (e.g. BitLocker) turned on.
  • Local-only app interface: the app's interface listens only on the local loopback address 127.0.0.1, so it cannot be reached from the network or the internet.
  • Secure sign-in: Google sign-in uses the OAuth 2.0 flow for installed apps with a random one-time state value to block forged sign-in requests. The app never sees or stores the user's Google password.
  • Least privilege: the app requests only two scopes, youtube.upload and youtube.readonly, and uses them only for the purposes described above.
  • Short-lived access: access tokens expire after about one hour and are refreshed only when an upload is made. Pressing "Disconnect" revokes the token with Google and deletes it from the computer.
  • No logging of secrets: tokens are not written to log files and are not shown in the interface.
  • Incident response: if we learn of a security issue affecting user data, we will fix it promptly and notify affected users by email.

5. Sharing

We do not sell, rent, transfer or disclose Google user data to any third party. Data is sent only to Google's own YouTube Data API endpoints to perform the upload.

6. Limited Use

Tan Seven Publisher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

7. Retention and deletion

  • Tokens are kept while the channel stays connected. Pressing "Disconnect" in the app revokes the token with Google and deletes it from the computer immediately.
  • You can also revoke access at any time at myaccount.google.com/permissions or Google security settings.
  • Upload records stay on the user's computer; the user can delete them at any time by deleting the app's data folder.
